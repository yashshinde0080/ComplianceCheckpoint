# Landing Page

The landing page is a standalone React application designed to showcase **Compliance Checkpoint**.

## Overview

It shares the same aesthetic principles as the main frontend application but is optimized for marketing and information presentation.

## Structure

- `src/components`: Landing page specific components (Hero, Features, Footer, etc.).
- `src/pages`: Landing page views.
- `src/index.css`: Theme styles mirroring the main app.

## Running Locally

To run the landing page development server:

```bash
cd landing_page
npm install
npm run dev
```
